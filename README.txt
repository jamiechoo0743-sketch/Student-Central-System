About this program:
This project is called "Student Central System".
It’s a simple Java program that lets users manage student info.
You can add, edit, and view students, filter them by course or status,
and also check who has the highest CWA or average per course.
There’s also a credit analysis to show how far each student has progressed.
The program reads data from a file called data.csv,
stores them inside Student objects, and keeps everything in an array.

--------------------------------------------------
Files included:
- App.java --> main program with all the menu and functions
- Student.java --> class for student info (id, name, details)
- Details.java --> class that stores course, year, cwa, status, credits
- data.csv --> file with example student data
- Declaration.pdf --> academic integrity declaration
- Assignment demo.mp4 --> screen recording showing the program working
- README.txt --> this file (just explaining what’s inside)
- Pseudocode.txt --> my planning before writing the code

--------------------------------------------------
How to run:
1. Put all the files in the same folder
2. Open terminal or command prompt in that folder
3. Type:  javac App.java
4. Then run:  java App
5. Follow the menu on screen to test each function
